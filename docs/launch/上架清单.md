## 1. ICP 备案（先做，最耗时）

### 1.1 提交前确认

- [ ] 小程序名称已设为「电耗账本」，与备案填写一致
- [ ] 主体信息已完善（个人：身份证；企业：营业执照 + 法人信息）
- [ ] 管理员微信可扫码、可完成人脸核验
- [ ] 负责人手机号为本人实名，能接收工信部短信

### 1.2 操作路径

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 选中小程序 → **设置 → 基本设置 → 小程序备案 → 去备案**。

看不到入口时，先补完主体信息与小程序基础信息。

### 1.3 需要填写的内容

| 模块 | 内容 |
|---|---|
| 主体信息 | 个人：姓名、身份证号、证件照、住址、手机、邮箱；企业：营业执照、法人信息、主体负责人证件 |
| 小程序信息 | 名称「电耗账本」、服务内容（工具/效率类）、类目（与后台服务类目一致） |
| 功能说明 | 记录电动汽车每次充电的里程、电量和花费，自动统计百公里电耗与每公里成本，支持 Excel 导入导出和上传充电订单截图自动识别；数据仅存储于用户本人的云端账本，不公开、不共享、不采集位置和通讯录 |
| 负责人 | 个人主体即本人，需微信人脸核验 |
| 应急联系人 | 一名可联系人员及手机号，通常不能与负责人相同 |

### 1.4 审核流程

| 环节 | 时长 | 注意 |
|---|---|---|
| 微信平台初审 | 1–2 个工作日 | 材料不全会被打回，按提示补 |
| 工信部短信核验 | 提交后 24 小时内 | **最容易失败的一步**：短信发到负责人手机，超时需重新排队 |
| 管局审核 | 1–20 个工作日 | 可能电话回访，保持手机畅通 |

### 1.5 注意事项

- [ ] 备案期间不改名称、主体、类目，改动需重新备案
- [ ] 只做「小程序备案」，**云开发不需要域名/网站备案**
- [ ] 备案免费，警惕「加急包过」收费代办

## 2. 小程序后台配置

- [ ] **服务类目**：设置 → 基本设置 → 服务类目。优先「工具 > 效率」，备选「工具 > 信息查询」；必须覆盖记录、统计、文件导入导出、图片识别
- [ ] **用户隐私保护指引**：设置 → 服务内容声明 → 用户隐私保护指引，声明以下隐私接口：
  - `wx.chooseMedia`（拍照/相册）→ 摄像头、相册
  - `wx.chooseMessageFile`（导入选文件）→ 选中的文件
  - `wx.openDocument` / `wx.shareFileMessage`（导出）→ 文件读写与转发
  - 图片上传云存储 → 说明仅用于充电订单识别，识别后删除云存储临时文件
  - 订单截图发送给 DeepSeek 多模态模型识别 → 声明第三方 AI 处理，仅提取电量/金额/SOC/站点等账本字段，不提取订单号、手机号、账号、支付方式、车牌
  - 数据用途：里程、充电、金额、备注仅用于用户本人的统计，存储于其云数据库，不公开、不共享、不采集位置/通讯录
