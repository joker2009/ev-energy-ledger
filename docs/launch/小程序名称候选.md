## 起名规则

- 名称不能**仅由通用词/行业词**组成（「电耗」「账本」「记账」都算）。
- 避免「账本、记账、账」：可能被联想为记账/金融服务，触发类目资质要求。
- 名称不能与已有小程序/公众号重复，不能侵权、不能含「微信」等。
- 长度约 4–30 个字符（1 个汉字按 2 个字符计），最终以后台校验为准。
- 名称需与小程序功能相关，不能完全无关。
- **名称修改次数有限，先用后台输入框实时查重，再正式提交。**

## E. 纯自造词（连续被拒后的优先方向）

> 连续两个名字未通过后新增。避开「账、本、充电、电耗」等描述性或经营词，降低通用词与资质联想风险。

| 名称 | 构成 | 说明 | 重名风险 |
|---|---|---|---|
| **度公里** | 度(kWh) + 公里 | 最不像现成词，重名概率最低 | 低 |
| **电迹** | 电 + 轨迹 | 两字，品牌感强，需简介解释 | 中低 |
| **千瓦记** | 千瓦 + 记录 | 工业感，生僻组合 | 低 |
| **电行记** | 电 + 出行 + 记录 | 读起来顺，功能可联想 | 低 |
| 瓦时记 | 瓦时(Wh) + 记录 | 更生僻，认知成本略高 | 低 |

## F. 品牌词（应对「通用词命名」驳回，优先方向）

> 2026-11-25 官方驳回原因：「涉及以通用词命名」。说明审核判定的是**显著性**，与是否被占用无关。
> 由描述功能的字典词拼成的名称（充电小本、电耗账本、电程记、度公里等）都会继续被拒。
> 对策：改用非词典词的品牌名，功能说明放到小程序简介里。不要再带「记 / 本 / 账 / 充电」等后缀。

| 名称 | 构成 | 说明 | 通过把握 |
|---|---|---|---|
| **橘电** | 橘 + 电 | 短、有温度，非现成词，保留行业联想 | 高 |
| **半度** | 半 + 度 | 取自「半度电」，两字品牌感强 | 高 |
| **电小满** | 电 + 小满（节气） | 整体是生造组合 | 较高 |
| **拾瓦** | 拾 + 瓦 | 工业感、生僻 | 高 |
| 度仔 | 度 + 仔 | 口语化、可爱 | 较高 |
| 青柚 | 纯品牌词 | 完全不含功能词，最稳；需简介解释功能 | 最高 |

## 推荐顺序

1. `橘电`
2. `半度`
3. `电小满`
4. `拾瓦`
5. `青柚`（兜底，纯品牌词）

## 查重与提交

1. 打开小程序后台 → 设置 → 基本设置 → 小程序名称。
2. 在输入框内逐个粘贴候选，观察是否提示「名称可用」。
3. 确认可用后再正式提交，避免浪费修改次数。
4. 被拒后查看名称审核结果里的具体原因，回填到本文件的「已用名称记录」。
